# Сервер и бот: как всё устроено

Владелец: ИП Масатбек (Марлен Кожабек). Язык общения: русский.

## Что работает 24/7 (на сервере Timeweb Cloud, Docker)
- Telegram-бот (@Skhanterbot): дважды в день (09:00 и 13:00 по Алматы, `TENDERS_TIMES`) ищет закупки на двух порталах: zakup.sk.kz и goszakup.gov.kz (товар,
  запрос ценовых предложений, 1,5–5 млн тг; `TENDERS_MAX_PRICE=0` снимает верхнюю границу), присылает только новые двумя отдельными
  списками (госзакупки и Самрук-Қазына), каждый по возрастанию суммы. Можно слать через отдельный бот (`TENDERS_BOT_TOKEN`). По закупкам zakup.sk.kz: точный товар,
  техническая спецификация, PDF, цены Satu.kz и маржа. По госзакупкам пока только список со ссылкой на объявление.
- Приложение «AI-офис» (папка `office/`): пиксельный офис, по сотруднику на команду, командный пункт внизу.
  Адрес: `http://IP_сервера:8787`, вход по ключу `APP_KEY`.
- Работает без компьютера пользователя. Проект на сервере: `/opt/montazhpro`, ветка `claude/ai-agent-vtido4`.
- Сервер нужно оплачивать в Timeweb (смотреть дату в панели), иначе он отключится.

## Файл настроек `/opt/montazhpro/.env.bot` (не в git, секреты только тут)
```
TELEGRAM_BOT_TOKEN=...      токен от @BotFather
ALLOWED_CHAT_IDS=799283726  chat id владельца
TENDERS_NOTIFY_MINUTES=60
APP_KEY=...                 ключ входа в приложение (не короче 12 символов)
# ANTHROPIC_API_KEY=...     необязательно: чат с ИИ и разбор товара
# TENDER_TAX_PERCENT=3, TENDER_EXTRA_PERCENT=5  для расчёта маржи
```
Файл правится через `cat > .env.bot` (Enter, строки, Ctrl+D). Осторожно: в серийной консоли длинные строки
искажаются, вводить короткими командами. Проверка: `cut -c1-22 .env.bot` (должны быть только строки `ИМЯ=значение`).

## Частые команды (на сервере, в `/opt/montazhpro`)
- Обновить и перезапустить: `git pull && docker compose up -d --build`
- Логи: `docker compose logs --tail 20 bot` (ищите «Бот запущен» и «AI-офис доступен на порту 8787»)
- Статус: `docker compose ps`; перезапуск без обновления: `docker compose restart bot`

## Команды бота и приложения
`/tenders`, `/tender 1275177`, `/price товар | цена заказчика`, `/help`, `/explore https://сайт` (изучить страницу нового
источника); можно словами: «тендеры», «цены кабель ВВГ». `/price 1275177` с номером закупки выполняет `/tender`.

## Агент «Спецификации»: бесплатный разбор без ИИ (работает всегда)
`tenders/spec_digest.py` (пакет pymupdf): из PDF спецификации лота достаёт таблицу «Параметр | Требование», условия поставки
(срок, оплата), описание текстом (если таблицы нет) и подсвечивает аналоги, документы/сертификаты, гарантию, стандарты (ГОСТ),
состояние товара, срок годности, комплектность. Бот присылает это в сообщении по закупке под заголовком «Разбор спецификации (по правилам, без ИИ)».
Ограничение: это структурирование текста, а не понимание: допустимость аналогов и соответствие товара оценивает человек.
Известный недочёт: в редких PDF буквы идут через пробел («Д л я»), это артефакт файла.

## Агент «Спецификации»: ИИ-разбор лота (дополнительно, нужен ключ)
Нужен `ANTHROPIC_API_KEY` в `.env.bot`. По `/tender номер` читает спецификацию каждого лота (до 3), определяет точный товар,
параметры, аналоги, что проверить и запрос для цен (цены Satu.kz ищутся по нему). Режим расходов: `TENDERS_AI=demand`
(по умолчанию, только по команде), `auto` (и по каждой новой закупке), `off`; модель `AGENT_MODEL` (дешевле: claude-haiku-5-5).
Без ключа бот это пропускает и пишет, что разбор выключен. Проверено только на подставной модели.

## Госзакупки (goszakup.gov.kz)
Коннектор `tenders/goszakup.py`: обычный запрос страницы поиска (сайт отдаёт таблицу в HTML, бывает очень медленным,
до 70 с на запрос; перенаправляет на old.goszakup.gov.kz). Фильтры: filter[method][]=3, filter[trade_type]=g,
filter[amount_from/to], filter[signs][]=is_active. Из облака Anthropic сайт закрыт (обрыв соединения): живой запуск
проверяется только на сервере. Проверка без браузера: `sh tenders/check_goszakup.sh`. Выключить: `GOSZAKUP=0`.
Подробный разбор карточки госзакупок (лоты, спецификация) не сделан: нужен `/explore` по ссылке вида
`https://goszakup.gov.kz/ru/announce/index/НОМЕР`.

## Чего пока нет / ограничения
- Цены только с Satu.kz. OLX блокирует автоматические запросы (не обходим), Kaspi не проверен с сервера.
- skstore.kz не подключён (закрыт по региону): проверить `curl -sI https://skstore.kz` с сервера или запустить `/explore`.
- Приложение работает по http без шифрования: позже домен и HTTPS.
- Видеомонтаж — отдельный бот `video-bot`, в офис не подключён.
- Защиту порталов не обходим: при ошибке бот сообщает код и не повторяет запрос.

## Безопасность (сделать)
- Токен бота и пароль root попадали в чат: отозвать токен (`/revoke` в @BotFather), сменить пароль root (`passwd`).
- Заменить простой `APP_KEY` на длинный.
