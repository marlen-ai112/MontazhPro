# OFFICE DUTY QUEST

Игровая система контроля дежурств в офисе: график на 7 дней, 5 обязательных заданий, XP, уровни, достижения, рейтинг, календарь истории и защищённая PIN-кодом панель администратора.
Стек: **React 18 + TypeScript + Tailwind CSS + lucide-react**, данные — **localStorage** (по умолчанию) или **Supabase**.

> Приложение лежит в папке `office-duty-quest/`; остальной репозиторий (Nuxt-сайт) не затронут.

## Запуск

```bash
cd office-duty-quest
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # продакшн-сборка в dist/
npm run preview    # проверка сборки
npm test           # юнит-тесты логики (XP, права, расписание, диф для облака)
npm run typecheck
```
Без настройки работает **локальный режим**: все данные хранятся в браузере (localStorage) и переживают перезагрузку.
Для первого входа выберите своё имя («Кто вы?»). PIN администратора по умолчанию — **1234** (смените в «Админ → Настройки»).

## Подключение Supabase (общая база для всего офиса)
1. Создайте проект на supabase.com.
2. SQL Editor → вставьте и выполните `supabase/schema.sql`.
3. Скопируйте `.env.example` в `.env.local` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (Project Settings → API).
4. Перезапустите `npm run dev` / пересоберите. В шапке появится значок облака.
5. При первом запуске пустая база заполнится сотрудниками и расписанием. Изменения отправляются разницей (diff), при обрыве связи копятся локально и досылаются, чужие изменения подтягиваются каждые 20 с.

**Безопасность.** Политики RLS в схеме разрешают запись анонимному ключу — это подходит для закрытого офисного приложения, но PIN тогда защищает только интерфейс. Для настоящей защиты включите Supabase Auth и ограничьте запись ролью `authenticated`. Облачный режим не проверялся на живом проекте (нет доступа из среды разработки) — код адаптера типизирован и покрыт тестом diff-логики.

## Структура базы данных
| Таблица | Назначение |
|---|---|
| `employees(id, name, position)` | сотрудники |
| `schedule_versions(effective_from, assignments jsonb)` | версии недельного расписания: `{"0":"e-donat",…}` (0 = Пн); новая версия не меняет прошлое |
| `schedule_overrides(date, employee_id)` | разовые замены дежурного |
| `task_marks(duty_date, task_id, marked_at, marked_by, marked_by_id, late)` PK `(duty_date, task_id)` | отметки; строка есть = выполнено, PK исключает дубли |
| `activity(id, at, kind, actor, duty_date, task_id, employee_id, detail)` | журнал действий |
| `settings(key, value)` | `deadlineHour`, `pinHash`, `startedOn` |

XP **не хранится**, а вычисляется из `task_marks` — поэтому двойное начисление невозможно (отмена/повтор/перезагрузка дают тот же итог).

## Архитектура
- `src/lib/state.ts` — чистая логика: расписание, отметки, права, сброс, демо-история.
- `src/lib/game.ts` — XP, уровни, рейтинг, достижения, статистика, статусы дней, просрочка.
- `src/storage/` — интерфейс `Repository`; `local.ts` (localStorage, защита от повреждённых данных), `supabase.ts` + `diff.ts`.
- `src/store/AppContext.tsx` — состояние, сессия, тосты, эффекты, синхронизация.
- `src/views/` — Главная, Задания, Рейтинг, История, Админ; `src/components/` — UI.

## Реализовано
- Тёмный игровой интерфейс (графит, синий/фиолетовый/золото), адаптив для телефона/планшета/ПК, нижняя навигация на мобильных, заставка загрузки.
- Недельный график Пн–Вс (Донат, Мустафа, Зиябек, Абубакр, Медет, Рамиль, Марлен): карточки с днём, датой, дежурным, статусом, %, кнопкой «К заданиям»; автоподсветка сегодняшнего дня; листание недель вперёд/назад.
- 5 заданий с чекбоксом, статусом, временем отметки, отменой; статус «Дежурство завершено».
- Права: сотрудник отмечает только своё дежурство (и не будущее); администратор — любые прошедшие/сегодняшние дни.
- XP: 20 за задание, +50 за все пять; уровни Новичок → Легенда офиса (0/150/450/900/1500 XP); 7 достижений, включая «Мастер порядка» (все задания недели без пропусков и в день дежурства); рейтинг за неделю и за всё время.
- Главная: круговой индикатор, счётчики, недельный прогресс, график, рейтинг, последние действия.
- История: календарь (зелёный/жёлтый/красный/серый), выбор любой даты, разбор 5 заданий с точным временем; история не обнуляется.
- Админ (PIN, защита от перебора): расписание (с даты, без изменения прошлого), разовые замены, переименование, исправление отметок, сброс дня с подтверждением, статистика, срок сдачи, смена PIN, экспорт/импорт JSON, демо-история, очистка истории.
- Эффекты: звук (WebAudio, переключатель), анимация «+XP», конфетти и экран победы, уведомление о новом дежурстве (раз в день), индикатор «Просрочено».
- Обработка ошибок: ErrorBoundary, недоступный localStorage, повреждённые данные (резервная копия + демо-данные), сбой облака.

## Ограничения
- В локальном режиме «кто вы» — выбор имени без пароля (доверие внутри команды); для настоящей авторизации используйте Supabase Auth.
- PIN хранится как хэш в данных приложения (в облаке — в `settings`).
