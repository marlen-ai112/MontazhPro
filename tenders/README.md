# Коннектор Playwright (Python) для zakup.sk.kz

`zakup_sk.py` открывает страницу поиска закупок в настоящем браузере и забирает список объявлений из ответа, который портал сам запрашивает у своего API. Фильтры: предмет «товар», способ «запрос ценовых предложений», опубликованные, сумма до `--price`.

Скрипт делает один обычный запрос за запуск, ничего не подделывает и не обходит защиту. Если портал отвечает ошибкой (например, 418), скрипт возвращает код ошибки и не повторяет запрос.

## Установка
```bash
pip install -r tenders/requirements.txt
playwright install chromium
```

## Запуск
```bash
python tenders/zakup_sk.py                          # до 5 000 000 тг
python tenders/zakup_sk.py --price 3000000 --max-items 10
python tenders/zakup_sk.py --min-price 1500000 --pages 6 --max-items 50   # диапазон 1,5-5 млн, 6 страниц
python tenders/zakup_sk.py --headed                 # показать окно браузера
```
Результат: JSON в stdout (`ok`, `status`, `items`, `error`). Код возврата 0 при успехе, 2 при ошибке.

Поля объявления: `number`, `nameRu`, `tenderType`, `sumTruNoNds`, `acceptanceBeginDateTime`, `acceptanceEndDateTime`, `advertStatus`.

## В Telegram-боте
`bot/index.js` уже регистрирует инструмент `search_tenders`, который запускает этот скрипт. Переменные: `PYTHON` (команда Python, по умолчанию `python` на Windows и `python3` в остальных системах), `TENDERS_HEADED=1` (показывать окно браузера).

## Автопоиск и рассылка в Telegram
Если запустить бота (`npm run bot`), он сам ищет закупки по расписанию и присылает в Telegram **только новые** (уже отправленные запоминаются в `bot/.state/`, файл в git не попадает). Первый запуск присылает весь текущий список. Команда `/tenders` присылает полный список по запросу.

| Переменная | По умолчанию | Значение |
|---|---|---|
| `TENDERS_NOTIFY_MINUTES` | 60 | как часто искать; `0` выключает автопоиск |
| `TENDERS_CHAT_IDS` | `ALLOWED_CHAT_IDS` | кому присылать |
| `TENDERS_MIN_PRICE` | 1500000 | сумма от, тг |
| `TENDERS_MAX_PRICE` | 5000000 | сумма до, тг |
| `TENDERS_PAGES` | 6 | сколько страниц портала просматривать |

Если портал не отвечает три раза подряд, бот пришлёт одно сообщение об этом.

## Подробности закупки: точный товар и техническая спецификация

`tenders/zakup_details.py --ids 1275177 --out-dir specs` открывает карточку закупки, читает лоты
(поле «точный товар» из `goodsAttributeList`, количество, цена, доставка) и скачивает PDF
«Техническая спецификация» каждого лота. Для текста из PDF нужен `pdftotext` (пакет `poppler-utils`).
Бот сам вызывает его по новым закупкам и по команде `/tender <номер>`.
Лотов может быть больше 10: портал листает их по 10, коннектор нажимает «следующую страницу», как человек
(проверено на закупке с 21 лотом).

## Цены и маржа

`tenders/prices.py --query "Насос ручной гидравлический 2л"` ищет товар на Satu.kz (данные schema.org со страницы поиска).
Бот для первых лотов закупки берёт точное название товара, сначала берёт точные совпадения (иначе похожие с предупреждением),
отбрасывает явные ошибки цен и считает маржу от цены заказчика: прибыль = цена заказчика × (1 − налог − прочее) − закупка.
Настройки: `TENDER_TAX_PERCENT` (3), `TENDER_EXTRA_PERCENT` (5), `TENDERS_PRICE_LOTS` (5), `TENDERS_PRICES=0` выключает.
Не подключены: OLX.kz (блокирует автоматические запросы, 405), Kaspi.kz (страница не отдаёт товары без полноценной загрузки).

## Госзакупки (goszakup.gov.kz)

`tenders/goszakup.py` делает обычный запрос страницы поиска объявлений (браузер не нужен, таблица приходит в HTML) с фильтрами сайта (способ `filter[method][]=3` = запрос ценовых
предложений, `filter[trade_type]=g` = товар, `filter[amount_from]`/`filter[amount_to]`, `filter[signs][]=is_active`).
Бот использует его как второй источник и присылает такие закупки с пометкой [госзакупки] и ссылкой на объявление.
Из облака Anthropic сайт закрыт, коннектор проверен на копии структуры таблицы; первый живой запуск делается на вашем сервере.
Выключить: `GOSZAKUP=0`. Страниц: `GOSZAKUP_PAGES` (3). Способы закупки: `GOSZAKUP_METHODS` (3; 126 = «не ГЗ»).
Для изучения нового сайта: команда бота `/explore https://сайт`.
