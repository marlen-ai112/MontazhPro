# AI-офис

Приложение для iPhone (веб-приложение, добавляется на экран «Домой»): пиксельный офис, где у каждой команды бота свой
сотрудник. Занят — сидит за компьютером, свободен — гуляет по офису. Внизу «командный пункт»: сюда приходят все результаты
(закупки, спецификации, цены и маржа, PDF), отсюда отдаются команды.

| Сотрудник | Команды |
|---|---|
| Поиск тендеров | `/tenders` |
| Спецификации | `/tender 1275177`: без ключа читает таблицу требований и условия из PDF по правилам; (с ключом Anthropic агент разбирает каждый лот: точный товар, параметры, аналоги, что проверить, запрос для поиска цен) |
| Цены и маржа | `/price насос ручной гидравлический 2л \| 130000` |
| ИИ-помощник | свободный текст (нужен `ANTHROPIC_API_KEY`) |
| Видеомонтаж | кнопка 📎: загрузите видео, в строке ввода можно написать заголовок и «стиль: кино» |

## Запуск

1. В `.env.bot` на сервере добавьте `APP_KEY=длинный_секретный_ключ` (от 12 символов). Без ключа приложение выключено.
2. `docker compose up -d --build`. Порт 8787 должен быть открыт в файрволе сервера.
3. На iPhone откройте в Safari `http://IP_сервера:8787`, введите ключ, затем «Поделиться» → «На экран Домой».

Демо без сервера: `office/index.html?demo=1`. На широком экране (от 900 пикселей) офис слева и командный пункт справа, на телефоне и узком окне вид как на iPhone.

## Безопасность

Адрес `http://` не шифрует трафик: ключ и данные идут открытым текстом. Для постоянной работы поставьте домен и HTTPS
(например, Caddy перед портом 8787). После 10 неверных попыток ключа IP блокируется на 10 минут.
