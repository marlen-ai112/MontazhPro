# Видеомонтажёр в Telegram (с ИИ)

Вы присылаете клипы или фото и референс, пишете задачу. Бот строит план монтажа через Claude, монтирует через ffmpeg и присылает видео обратно в чат.

## Как это работает
1. Claude смотрит кадры референса и ваших клипов и заполняет **структурный план** (какие куски, переходы, подписи, цвет, формат). Команды ffmpeg он не пишет.
2. Модуль `render.js` проверяет план по белому списку и монтирует ffmpeg (без shell).
3. Готовый ролик отправляется в чат. Правки: «сделай короче», «убери подписи», «чёрно-белое».

## Что нужно
- Node.js 20+ и **ffmpeg** (с ffprobe) в PATH. Windows: `winget install ffmpeg`.
- Токен бота от @BotFather и ключ Anthropic.

## Запуск
```bash
set TELEGRAM_BOT_TOKEN=...      # Windows (cmd); в bash: export ...
set ANTHROPIC_API_KEY=...
set ALLOWED_CHAT_IDS=ваш_chat_id
npm run video-bot
```
Напишите боту `/start`: он покажет ваш chat id. Подставьте его в `ALLOWED_CHAT_IDS`, чтобы бот отвечал только вам.

## Как пользоваться
1. Пришлите клипы или фото (по одному сообщению на файл).
2. Видео-образец пришлите с подписью **«референс»**.
3. Напишите задачу: «ролик 20 секунд для Reels с подписями».
4. Команды: `/status`, `/reset`.

## Ограничения
- Telegram Bot API: скачивание файлов до **20 МБ**, отправка до **50 МБ**. Для больших файлов нужен локальный Bot API server.
- Подписи в кадре используют шрифт Arial (Windows) или DejaVu (Linux). Свой шрифт: переменная `FONT`.
- Максимум 12 клипов и 90 секунд итогового видео.

## Субтитры по речи
Добавьте в задачу «с субтитрами». Бот извлечёт звук из готового видео, распознает речь и наложит текст внизу кадра (обычные подписи при этом уходят наверх).

Нужен ключ сервиса распознавания речи, совместимого с Whisper API:

| Переменная | Значение |
|---|---|
| `STT_API_KEY` | ключ (обязателен) |
| `STT_BASE_URL` | по умолчанию `https://api.openai.com/v1`; для Groq: `https://api.groq.com/openai/v1` |
| `STT_MODEL` | по умолчанию `whisper-1`; для Groq: `whisper-large-v3` |
| `STT_LANGUAGE` | по умолчанию `ru`; пустое значение включает автоопределение |

Без `STT_API_KEY` бот пришлёт видео без субтитров и объяснит, почему. Ошибка сервиса распознавания тоже не ломает монтаж. Если в клипах нет звука или речи, субтитры не добавляются.
